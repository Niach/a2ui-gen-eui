# a2ui-gen-eui

Generates A2UI Express user interfaces for the eui catalog with a small local model: llama.cpp inference,
grammar-guided decoding, validation through the [`a2ui-express`](https://crates.io/crates/a2ui-express)
compiler, streaming output. No Python and no network calls during inference.

Work in progress: the crate and the `generate_ui` MCP server land in the first pull request.
